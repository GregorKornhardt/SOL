How to read these results

Reference = the text to match. G uses held-out GPT-2-packed OpenWebText. E uses text decoded from ELF’s training corpus. B uses held-out OpenWebText in BD3-LM’s training format, without block-edge tokens. Every row carries its reference badge, G, E or B. All references share one SOL ranking. Rows are sorted together by the selected column.

Encoder = the token representation. Dream 7B and GPT-2 Large turn text into hidden token states before SOL compares them. Select one encoder for a comparison; their raw score scales differ. Dream 7B is selected by default.

Real–real control = sampling variation. Two finite samples of real text still differ. The control gives context for G and E; the table has no real–real control for B. Lower SOL means closer to that reference; it is not an individual text quality grade.
